# Healer Dealer Pharmacy Database

A database design project for a pharmacy management system, developed for the CSC375 Database Management Systems course.

The project models the operations of a pharmacy, including employees, branches, inventory, suppliers, medicines, self-care products, customers, prescriptions, billing invoices, and pharmacy transactions.

## Features

- ER diagram and entity-relationship modeling
- ER-to-relational mapping
- SQL table creation using Oracle SQL
- Sample data insertion
- Pharmacy-related transaction queries
- Expired medicine detection
- Supplier payment summary
- High-risk customer detection
- Normalization up to BCNF

## Technologies

- SQL
- Oracle Database
- Database Design
- ER Modeling
- Relational Mapping
- BCNF Normalization
